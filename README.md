# Nebula Drive Dashboard (Preview)

A stylish web dashboard prototype for a personal cloud-storage experience.

## Run local preview

1. Install dependencies:

```bash
npm install
```

2. Start live preview server:

```bash
npm run preview
```

3. Open in browser:

```text
http://localhost:1234
```

## Build production bundle

```bash
npm run build
```

## Download app package (.zip)

Generate a downloadable app bundle:

```bash
npm run download-app
```

Output file:

```text
releases/nebula-drive-dashboard.zip
```
